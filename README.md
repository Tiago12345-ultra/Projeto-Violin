# Projeto-Violin
# Biblioteca e Empréstimo de Livros

## Nomes dos participantes

Cassiele Silveira, Vitor Augusto e Tiago Valadares.

## Tema do projeto/aplicação

Biblioteca e empréstimo de livros.

## Breve resumo do problema que irá resolver

Bibliotecas escolares pequenas podem ter dificuldades para controlar os empréstimos de livros, os atrasos e a disponibilidade do acervo. O projeto busca facilitar esse controle.

## Requisitos Funcionais

- Cadastrar livros.
- Cadastrar leitores.
- Realizar empréstimos de livros.
- Realizar devoluções de livros.
- Consultar livros e leitores.

## Requisitos Não Funcionais

- O sistema deverá ser uma aplicação web.
- O sistema deverá utilizar uma API para comunicação entre as partes.
- Os dados deverão ser armazenados de forma organizada.
- O sistema deverá ser versionado utilizando Git e GitHub.
